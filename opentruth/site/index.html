Did the software actually satisfy the requirement?

OpenTruth is the verifier, never the builder. It operates the running system, records a hash-sealed evidence graph, and returns a verdict. AI-built software is the urgent case. The protocol still applies when the builder is human. This site is a control surface for that engine — not a second OpenTruth.

01 / Identity

Protocol. Product. Adapter.

Three parts, one trust boundary. The builder may declare. The engine decides.

Protocol

Independent proof

Runners, A/O/E, seal, and E-only verdicts. The planner can change; this machinery does not.

Product

Simple interfaces

CLI, GitHub Action, and this site call the same verifier. Complex protocol. Simple interface.

Adapter

Declarations only

A coding agent may prepare YAML. It must not write evidence, hashes, or a verdict.

02 / Thesis

Verifier ≠ Builder.

The same agent that shipped the feature is not the entity that decides it works. OpenTruth never writes tests into the target repository. PROVEN is required coverage executed, required assertions established, an intact evidence chain, and a seal that still matches — not a log line.

  • PROVENRequired coverage executed, required assertions hold, evidence chain intact, seal valid.
  • PARTIALLY_PROVENHappy path holds; at least one constraint fails — MiniAuth session, MiniTodos complete-persist.
  • FAILEDThe required happy path was observed not to hold.
  • NOT_PROVENNot enough evidence to establish the claim. Not the same as FAILED.
  • INCONCLUSIVECould not observe (app down, timeout). Not a pass and not a product failure.

04 / Layers

Six proof layers. One graph.

Each milestone writes into the same sealed namespaces: R-*, C-*, A-*, O-*, E-*. Nothing else is the product.

M1

Browser proof

Operate the UI in Chromium. Observable behavior becomes actions, observations, assertions.

M2

API proof

Direct HTTP: valid, invalid, unauthorized, state transitions. Same graph, kind: http.

M3

State proof

After the system claims success, read durable storage. Invariants, not dashboards.

M4

Change proof

Two sealed runs. What improved, held, or regressed. Differential evidence cites both run IDs.

M5

Continuous

The CLI in CI. Exit code plus a packed sealed run. Still not a service.

M6

AI-assisted plan

An LLM may propose plan.json. It never writes verdict.json.
