Evidence model

The run directory is the product.

Every file is hashed into manifest.json last. JSONL is append-only. IDs are never reused. Tamper any file and the verdict is no longer evidence.

.opentruth/runs/<run-id>/
  manifest.json
  requirements.json
  plan.json
  actions.jsonl
  observations.jsonl
  assertions.jsonl
  screenshots/
  network/
  artifacts/
  verdict.json
  • R-*Requirement. One statement, frozen for the run.
  • C-*Constraint. Child of one requirement. C-0 is the happy path.
  • A-*Action the verifier took: click, HTTP, SQL, compare.
  • O-*Observation: screenshot, HTTP body, DB rows, diff side.
  • E-*Assertion citing observations. The only input to the verdict.
Integrity

Hashes, then the word PROVEN.

Confidence is passed / conclusive assertions. INCONCLUSIVE is excluded from the denominator so a crash cannot look like a product failure. That is the analogue of distinguishing verifier-inability from product-failure.
