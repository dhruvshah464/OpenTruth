Six kinds of proof.

Requirement and declared environment → deterministic plan IR → independent runner → append-only A / O / E records → verdict.json → seal manifest.json. Explain walks the graph and checks hashes.

  • M1 BrowserPlaywright as a browser, not as a test generator. Locators are roles and labels. Missing controls are INCONCLUSIVE, not invented CSS.
  • M2 APIDeclared routes only. Cookie jar for authed calls; a second opener for unauthorized. Observations kind: http.
  • M3 StateSQLite after HTTP setup. The MiniAuth identity row is skipped unless the plant is disabled — UI still “works.”
  • M4 Diffimproved / regressed / unchanged / changed. Any regression is FAILED. Integrity fail on either source is INCONCLUSIVE.
  • M5 CIExit 0 only for PROVEN. Pack refuses a tampered directory. GitHub Action uploads the zip; still no hosted service.
  • M6 LLM planAllowlisted IR. Hostile kinds and DROP TABLE are rejected. A model that returns "verdict": "PROVEN" does not decide the verdict.
Not built

The freeze is the product discipline.

After M6 we do not schedule automatic requirement discovery, unfamiliar-repo analysis, multi-agent verification, production observability, verification marketplaces, or enterprise dashboards. Those are how a verification engine becomes an unfinished SaaS.
