Company

A verification lab,
not a SaaS backlog.

OpenTruth is an open verification protocol for independently establishing software requirements from executable evidence. AI-built software made the gap urgent. The protocol remains useful when the builder is human. Nearby slots — test generators, claim checkers, spec gates, formal methods — are occupied. The unoccupied gap is live operation of the product, with a walkable, hash-sealed graph.

Position

Deep tech is the constraint set.

We optimize for defensible verdicts. The planner can change; the notebook machinery does not. If a change does not make PROVEN more defensible, it waits.

Independence

Separate from the builder

Evidence is never written into the repository the agent just edited.

Integrity

Tamper is visible

Rewrite any sealed file and the run is no longer evidence.

Refusal

INCONCLUSIVE is honest

Inability to observe is not a product failure and not a pass.

What we will not become

Automatic requirement discovery, unfamiliar repository analysis, multi-agent verification, production observability, verification marketplaces, enterprise dashboards. Named so the lab stays an engine.
